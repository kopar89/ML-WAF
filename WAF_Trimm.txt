' =======================================================
' RELATIONSHIPS
' =======================================================

' Ingress Flow
CDN --> ReverseProxy : Forward Traffic
ReverseProxy --> WAFCore : Proxied Requests

' WAF Core internals
WAFCore *-- Config
WAFCore *-- PluginManager
WAFCore *-- SecurityEngine
WAFCore *-- EventPublisher
WAFCore ..> IdentityProvider : Validate JWT
WAFCore ..> MetricsExporter : Export Metrics
WAFCore ..> LogManager : Write Logs
WAFCore ..> TracingManager : Trace Requests

' Event flow
EventPublisher --> MessageBus : Publish Events
EventPublisher ..> SchemaRegistry : Validate Schema

' Message Bus internals
MessageBus *-- SchemaRegistry
MessageBus --> StreamProcessor : Stream Events
MessageBus --> ComplexEventProcessor : CEP
MessageBus --> EventStore : Persist Events
StreamProcessor --> StreamingAnalytics : Feed Analytics
EventStore --> StreamReplayer : Replay

' Security Engine
SecurityEngine *-- RuleManager
SecurityEngine ..> BotDetectionEngine
SecurityEngine ..> APISecurityLayer
SecurityEngine ..> ThreatIntelligenceFeed
SecurityEngine ..> BehavioralBaseliner

RuleManager *-- RuleCompiler
RuleManager ..> Rule

SecurityEngine ..> SQLInjectionDetector
SecurityEngine ..> XSSDetector
SecurityEngine ..> CommandInjectionDetector
SecurityEngine ..> FileInclusionDetector
SecurityEngine ..> BusinessLogicDetector
SecurityEngine ..> XXEDetector
SecurityEngine ..> SSRFDetector

' API Security
APISecurityLayer --> RateLimitCache : Check/Update Limits

' Bot Detection
BotDetectionEngine --> SessionStore : Session Management
BotDetectionEngine ..> ThreatIntelligenceFeed : IP Reputation

' State → Message Bus
RateLimitCache --> MessageBus : Rate Limit Events
SessionStore --> MessageBus : Session Events
AttackSignatureCache --> MessageBus : Signature Updates

' ML
PluginManager ..> GRPCMLClient
GRPCMLClient --> MLInferenceService : gRPC
MLInferenceService --> MessageBus : ML Predictions
MessageBus --> MLInferenceService : Training Data
BehavioralBaseliner ..> AnomalyDetectionModel

' Observability
LogManager --> Elasticsearch : Index Logs
MetricsExporter --> Prometheus : Scrape
Prometheus --> Alertmanager : Alerts
TracingManager --> Jaeger : Traces
Alertmanager --> MessageBus : Publish Alerts

' Infra
Kubernetes --> WAFCore : Run
Kubernetes --> MLInferenceService : Run
ConfigStore --> WAFCore : Config Watch
SecretManager --> Kubernetes : Secret Injection
Config ..> ConfigStore : Load/Watch
